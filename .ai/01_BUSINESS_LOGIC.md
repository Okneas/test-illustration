# Бизнес-логика и ограничения

## Ключевые ограничения
1. **Запрет на изменение объектов:** Категорически нельзя менять path, viewBox или пропорции элементов внутри компонента. Объект должен копироваться "как есть".
2. **Векторность:** Запрещено использовать растровые изображения (canvas, png, jpg). Только SVG-деревья.
3. **Цветовые схемы:** 
   - Существует 3 предустановленные схемы (в будущем больше).
   - Есть цвета для Главных объектов (цветные) и Фоновых (монохром).
   - *Правило:* Цвета фонов могут использоваться в объектах. Цвета объектов НЕ МОГУТ использоваться в фонах.

## Сценарии работы
### Сценарий 1: Сборка по метафоре/заголовку
1. Пользователь вводит текст (например: "Успешный стартап", "Искусственный интеллект").
2. Сервис отправляет запрос к LLM (или использует захардкоженный маппинг для демо).
3. LLM возвращает массив тегов и ID компонентов, подходящих под метафору.
4. Сервис автоматически размещает эти компоненты на холсте (базовый auto-layout).

### Сценарий 2: Сборка по названиям компонентов
1. Пользователь вводит названия компонентов (например: "Компьютер, Дерево, Человек").
2. Сервис ищет совпадения в библиотеке (по name и tags).
3. Пользователь выбирает из найденных вариантов (с учетом размера иллюстрации).
4. Компоненты добавляются на холст.

## Правила композиции
- **Размеры:** Существует 2 размера иллюстраций (S и L). Разница в детализации. При смене размера холста компоненты должны автоматически подменяться на соответствующие (S -> L).
- **Состояния объектов:** Объект может быть "Главным" (Main) или "Фоновым" (Background). 
  - Главный: использует полную цветовую палитру.
  - Фоновый: использует только монохромную палитру (серый/черный).
- **Трансформации:** Разрешено перемещение (X, Y), поворот (rotation), дублирование, удаление, изменение z-index (порядок слоев). Масштабирование (scale) запрещено, если оно нарушает пропорции.
