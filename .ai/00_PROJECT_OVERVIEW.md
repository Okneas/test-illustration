# Проект: Конструктор иллюстраций на базе SVG

## Описание
Веб-сервис для автоматизированной сборки композиций из заранее подготовленных SVG-компонентов (библиотека из 20 иллюстраций). Сервис не генерирует новые объекты, а только собирает, трансформирует и перекрашивает существующие, сохраняя строгую векторную структуру.

## Технологический стек
- **Frontend:** React 18+, TypeScript, Vite.
- **UI:** Tailwind CSS, shadcn/ui (Radix UI).
- **State Management:** Zustand (идеально для управления состоянием холста и объектов).
- **Работа с SVG:** DOMParser, XMLSerializer (нативные браузерные API), vite-plugin-svgr (для импорта).
- **Экспорт:** FileSaver.js или нативный Blob API.

## Архитектура (Backend vs Frontend)
Бекенд **не требуется** для базовой работы. 
- Хранение компонентов: статические SVG-файлы в папке `public/assets/components`.
- Перекраска и трансформация: происходят на клиенте путем модификации DOM-дерева (изменение атрибутов `fill`, `stroke`, `transform`).
- Для Сценария 1 (AI): использование клиентского запроса к LLM с системным промптом для сопоставления метафоры с тегами доступных компонентов.

## AI-инструменты при разработке

- Figma MCP (для извлечения SVG-компонентов и цветовых схем).
