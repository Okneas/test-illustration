# UI/UX Гайдлайн
## Общий layout
- **Left Sidebar (Панель управления):** Выбор размера (S/L), выбор цветовой схемы, кнопка "Собрать по метафоре" (модалка с инпутом), поиск компонентов по названию.
- **Center Canvas:** Холст с сеткой (или без), где происходит рендер объектов.
- **Right Sidebar (Свойства):** Отображается при выборе объекта. Позволяет менять X, Y, Rotation, Z-index, переключать состояние (Main/Background), кнопки дублирования и удаления.
## Компоненты shadcn/ui для использования
- `Button`: для действий (экспорт, добавить, удалить).
- `Select`: для выбора размера и цветовой схемы.
- `Input`: для поиска компонентов и ввода метафоры.
- `Dialog`: для окна ввода метафоры (Сценарий 1).
- `Slider`: для изменения поворота (Rotation) или координат (опционально).
- `ContextMenu` (Radix): правый клик по объекту на холсте (дублировать, на передний план, на задний план, удалить).
- `Tabs`: для переключения между "Библиотекой" и "Слоями".
## Взаимодействие с холстом
- Использовать `react-rnd` (или аналогичную легковесную библиотеку) для drag-and-drop объектов на холсте. Она позволяет легко реализовать перемещение и изменение размеров (если понадобится).
- Для поворота можно использовать кастомный слайдер в правой панели или реализовать ручку поворота на самом объекте.
